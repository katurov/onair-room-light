# OnAirService Agent Instructions

Этот проект предназначен для мониторинга состояния мультимедийных устройств в macOS.

## Технический стек
- **Python 3.10+**
- **PyObjC**: Прямое взаимодействие с macOS фреймворками.
- **uv**: Управление зависимостями через inline metadata в начале `OnAirService.py`.

## Правила редактирования
1. **PID Protection**: Не удаляй логику `check_pid()` и `cleanup()`. PID-файл должен находиться в `/tmp/OnAirService.pid`.
2. **Logging**: Используй `logger` вместо `print`. 
   - `INFO`: Смена состояний, старт/стоп.
   - `WARNING`: Проблемы с сетью или занятый PID.
   - `ERROR`: Фатальные ошибки macOS API.
3. **RunLoop**: Скрипт использует `AppHelper.runConsoleEventLoop()`. Любые долгоиграющие операции должны выполняться асинхронно или через `NSTimer`, чтобы не блокировать цикл событий.
4. **Indicators**: Основной IP индикатора — `192.168.42.247`. Эндпоинты: `/video` (Green) и `/air` (Yellow).
5. **Interval**: Интервал опроса по умолчанию — 8.0 секунд.

## Проверка перед коммитом
- Проверь корректность импортов `objc` и фреймворков.
- Убедись, что inline metadata в `OnAirService.py` содержит все необходимые `pyobjc-framework-*`.
